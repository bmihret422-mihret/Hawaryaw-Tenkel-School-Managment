# Hawaryaw Tenkel School Management System

A web-based application designed to simplify school management and student information handling.

## Project Overview

This project aims to help schools manage their academic and administrative activities efficiently.

## Features

- Student Management
- Teacher Management
- Student Registration
- Department Management
- Dashboard
- Search and Update Records

## Technologies Used

- CSS
- JavaScript
